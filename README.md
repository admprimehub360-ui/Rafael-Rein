# Rafael Rein — Árvore do Conhecimento

Site pessoal interativo de Rafael Rein, com uma Árvore do Conhecimento que conecta trajetória, gestão, estratégia, métodos e inteligência artificial.

## Estrutura

- `dist/`: site estático, pronto para hospedagem.
- `dist/index.html`: página principal.
- `dist/territorio.html`: ambientes da árvore.
- `dist/ambiente.html?area=Todos`: acervo de materiais.

## Execução local

Sirva a pasta `dist/` com um servidor HTTP estático, por exemplo `npx serve dist`.

Este repositório contém apenas os arquivos públicos de execução do site. As configurações privadas da hospedagem não fazem parte do código publicado aqui.
